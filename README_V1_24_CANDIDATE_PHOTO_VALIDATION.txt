V1.24 — CANDIDATE PASSPORT-PHOTO VALIDATION

Every new or replacement Candidate Photo is now validated on the server before
it can be saved. The validator requires exactly one clear, front-facing and
properly centred face, adequate resolution and sharpness, and a predominantly
plain white or orange background.

NOTE: The background-colour restriction above was superseded by V1.32. The
current rule accepts a plain background of any colour while rejecting visually
busy backgrounds.

The rule applies to new applications, pending-document replacements and
rejected-photo corrections. Payment Evidence is unaffected. Applicants receive
a specific correction message when the photograph fails a check, while the
administrator retains the existing final review and approval responsibility.
