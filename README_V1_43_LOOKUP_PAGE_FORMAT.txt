V1.43 - LOOKUP PAGE FORMAT

Candidate portal pages now use the same visual structure as the established ID
to Serial Number and Voter Polling Centre lookup pages:

- light grey page background
- centred white card with rounded corners and soft shadow
- ODM voting banner inside the card
- strong labels and larger input fields
- black full-width public action buttons with orange borders
- simple in-card navigation instead of the old black/yellow page bars
- responsive mobile spacing

The shared format applies to candidate access, new registration, candidate
forms, administrator login/dashboard, final-list notice and database fallback.
