V1.32 — ANY-COLOUR PLAIN CANDIDATE-PHOTO BACKGROUND

Candidate passport photos may now use a plain background of any colour.

The browser crop check and the authoritative server validator no longer require
white or orange. They inspect the background for visual detail instead, so a
plain wall, sheet or studio background with gentle lighting or colour gradients
can pass. Photos containing scenery, patterns, text, objects or other visually
busy background detail are rejected.

The existing server checks remain in force: the crop must contain exactly one
clear, front-facing candidate face of a suitable size, position and sharpness.
Photos without a detected candidate face are not accepted.
