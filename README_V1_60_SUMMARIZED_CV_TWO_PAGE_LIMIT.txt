2027 CANDIDATE REGISTRATION PORTAL V1.60
=========================================

Added Summarized Curriculum Vitae – 2 page maximum as a required PDF
attachment.

The server reads the uploaded PDF and rejects it when:

- it is not a genuine readable PDF;
- it is encrypted or damaged;
- it exceeds 5 MB; or
- it contains more than two pages.

The saved CV is available securely to the applicant and administrator and must
be present before the application can be submitted or approved.
